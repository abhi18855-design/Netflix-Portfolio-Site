Publish your changes

Download and extract the ZIP. Upload the extracted files into your GitHub repository, then commit. Do not upload the ZIP itself. On Mac, press Command + Shift + . to reveal hidden files and include .github and .pages.yml. Keep existing deployment files in the repository. Wait for the Actions build to finish before refreshing the live site.

Reopen the updated editor after deployment to continue editing. Save a backup before closing this tab. The editor exports source files; it does not publish to GitHub, and does not provide a live rendered preview. To remove an existing project without leaving an old file on GitHub, turn off its Published setting.
